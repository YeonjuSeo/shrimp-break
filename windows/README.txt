새우 브레이크 (Windows)
======================

정해진 시간마다 화면 아래에서 새우가 튀어나와 "자세 바꿀 시간!"을 알려줘요.
새우를 아무거나 하나 클릭하면 전부 사라지고 다음 타이머가 시작돼요.

[실행 방법]  Windows 10 / 11
1. 이 폴더(ShrimpBreak)를 통째로 원하는 곳에 두세요. 예) 문서 폴더
   (ShrimpBreak.exe.config 도 exe 옆에 같이 있어야 메뉴 글자가 화면 배율에 맞게 나와요)
2. ShrimpBreak.exe 를 더블클릭
3. "Windows의 PC 보호" 파란 창이 뜨면 → [추가 정보] → [실행]
   (정식 인증서로 서명하지 않은 앱이라 처음 한 번 뜨는 경고예요)
4. 작업 표시줄 오른쪽 아래(시계 옆)에 앉은 사람 아이콘이 생기면 끝!
   아이콘이 안 보이면 ^ (숨겨진 아이콘 표시) 안에 있어요. 끌어서 밖으로 꺼내 두면 편해요.

[사용 방법]
- 아이콘 클릭 → 메뉴 (알림 간격, 앉기·서기 시간 따로 설정, 일시정지, 자동 실행)
- 아이콘에 마우스를 올리면 남은 시간이 보여요
- 앉은 사람 아이콘 = 앉아 있을 차례 / 선 사람 아이콘 = 서 있을 차례
- 화면 잠금·절전, 또는 5분 동안 입력이 없으면 자리를 비운 것으로 보고 타이머를 멈춰요.
  돌아오면 앉는 차례부터 처음부터 다시 세요.

[삭제]
메뉴에서 "Windows 시작 시 자동 실행" 끄기 → 종료 → 폴더 삭제

[문제가 생기면]
오류 내용이 %LOCALAPPDATA%\ShrimpBreak\error.log 에 저장돼요. 이 파일을 보내 주세요.
