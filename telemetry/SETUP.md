# 사용 통계 시트 연결하기 (처음 한 번)

앱이 보낸 익명 통계를 구글 시트에 쌓으려면, 시트에 "받는 창구"(Apps Script 웹 앱)를 하나 만들어야 해요.
약 5분 걸려요.

## 1. 코드 붙여 넣기
1. 통계용 구글 시트를 열어요.
2. 메뉴 **확장 프로그램 › Apps Script**를 눌러요. 새 탭에 코드 편집기가 열려요.
3. 편집기에 있던 `function myFunction() { … }`을 모두 지우고, `telemetry/apps-script.gs`의 내용을 전부 붙여 넣어요.
4. 저장해요 (⌘S).

## 2. 탭·대시보드 만들기
1. 편집기 위쪽의 함수 선택 칸에서 **`setup`**을 고르고 **▶ 실행**을 눌러요.
2. "승인 필요" 창이 뜨면 **권한 검토 → 내 구글 계정 선택**을 눌러요.
   - "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)(으)로 이동(안전하지 않음)** → **허용**을 눌러요.
   - 내가 만든 스크립트가 **이 시트에만** 쓰기 권한을 받는 거라 괜찮아요.
3. 시트로 돌아가면 `dashboard`, `install`, `settings`, `daily`, `consent` 탭이 생겨 있어요.

## 3. 웹 앱으로 배포하기
1. 편집기 오른쪽 위 **배포 › 새 배포**를 눌러요.
2. 톱니바퀴(유형 선택)에서 **웹 앱**을 골라요.
3. 설정:
   - **다음 사용자 인증 정보로 실행**: 나
   - **액세스 권한이 있는 사용자**: **모든 사용자**
     (앱은 로그인 없이 보내야 해서 이게 필요해요. 이 주소로는 정해진 형식의 통계만 기록되고, 시트를 읽을 수는 없어요.)
4. **배포**를 누르면 **웹 앱 URL**이 나와요: `https://script.google.com/macros/s/……/exec`
5. 이 URL을 복사해서 전달해 주세요. (또는 `telemetry/endpoint.txt` 파일에 한 줄로 저장)

> 회사 구글 계정에서 "모든 사용자"가 선택지에 없으면, 회사 정책으로 막힌 거예요. 개인 구글 계정으로 만든 시트에서 다시 해 주세요.

## 나중에 코드를 고치면
**배포 › 배포 관리 › (연필) 수정 › 버전: 새 버전 › 배포**로 다시 배포해야 반영돼요. URL은 그대로예요.
대시보드 항목이 바뀐 경우에는 편집기에서 `setup` 함수를 한 번 더 실행해 dashboard 탭을 다시 만들어요 (기존 기록은 그대로).

## 시트에 쌓이는 것
| 탭 | 한 줄 = | 내용 |
|---|---|---|
| `install` | 통계에 동의한 설치 1건 | OS, 버전, 언어, 모니터 수, 처음 설정값 |
| `settings` | 설정 변경 1건 | 무엇을, 이전 값 → 새 값, 몇 시에 |
| `daily` | 한 사람의 하루 | 알림·클릭 수, 몇 마리에서 일어났나, 버틴 시간, 새우/튀김, 앉은/선/움직인 시간, 일시정지·자리 비움, 시간대별 횟수 |
| `consent` | 통계 켬/끔 1건 | 처음 실행 때 선택, 메뉴에서 켜고 끈 기록. "안 보내기"는 고유 ID 없이 한 번만 기록 |
| `dashboard` | 요약 | 위 내용을 수식으로 집계 (테스트 빌드 기록은 제외) |

이름·이메일·컴퓨터 이름·IP 주소는 저장하지 않아요. `id`는 앱이 설치 때 만든 무작위 값이에요.
