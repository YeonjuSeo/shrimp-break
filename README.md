# 🦐 새우 브레이크 (ShrimpBreak)

**새우등 방지 타이머** 🦐

허리를 지키려면 오래 서 있기 ❌ 자주 자세 바꿔 주기 ⭕ 해야 하는 거 아시죠?
한 자세로 너무 오래 있으면 화면 바닥에서 새우(가끔 튀김)가 튀어나와서 알려 드립니다.

Mac(메뉴바)·Windows(작업 표시줄) 둘 다 가능 → **[최신 버전 받기](https://github.com/YeonjuSeo/shrimp-break/releases/latest)**

## Features

### 🪑 앉기 → 🧍 서기 → 💃 움직이기

- 메뉴에서 시간을 입력하면 세 루틴을 차례로 반복합니다. 0분으로 두면 스킵합니다.
- 메뉴바 아이콘으로 현재 차례를 확인하세요.
- 타이머 초기화, 원하는 루틴 바로 시작, 일시정지도 메뉴에서 가능합니다.

### 🦐 시간이 되면 새우로 알려드립니다

- 다양한 크기의 새우... 가끔 새우튀김도 나와요.
- 자세를 바꾸면 새우를 클릭해주세요. 버티면 새우가 점점 많아집니다.

### 🌊 파도

- 새우를 클릭하시고 근심걱정... 그리고 모든 새우를 날려버리세요.

### 📊 익명 사용 통계 (선택)

- 처음 실행할 때 보낼지 물어봐요. 이름·이메일·컴퓨터 이름은 보내지 않고, 메뉴에서 언제든 끌 수 있어요.

## 추천 루틴

|                    | 🪑 앉기 | 🧍 서기 | 💃 움직이기 |
| ------------------ | ------- | ------- | ----------- |
| 기본 (30분 사이클) | 20분    | 8분     | 2분         |

- 서 있는 시간보다 자세를 자주 바꾸는 게 더 중요하다고 합니다.

## 설치

**Mac** (Apple Silicon·Intel)

1. 릴리스에서 `ShrimpBreak-Mac-*.zip`을 받아 압축을 풀고, `ShrimpBreak.app`을 응용 프로그램 폴더로 옮겨요.
2. 더블클릭 → "확인되지 않은 개발자" 경고가 뜨면 **시스템 설정 › 개인정보 보호 및 보안** 맨 아래에서 **그래도 열기**를 눌러요 (처음 한 번만).

**Windows** (Windows 10/11, 따로 설치할 것 없음)

1. 릴리스에서 `ShrimpBreak-Windows-*.zip`을 받아 압축을 풀고 `ShrimpBreak.exe`를 실행해요.
2. "Windows의 PC 보호" 창이 뜨면 **추가 정보 › 실행**을 눌러요 (처음 한 번만).

## 공유하기

### Mac

```bash
scripts/package.sh            # → dist/ShrimpBreak.zip (Apple Silicon + Intel, 테스트 메뉴 없음)
```

받는 사람: zip 풀기 → `ShrimpBreak.app` 을 응용 프로그램 폴더로 옮기기 → 더블클릭.
"확인되지 않은 개발자" 경고가 뜨면 **시스템 설정 › 개인정보 보호 및 보안** 맨 아래
"그래도 열기" → 암호 입력.

터미널이 편하다면

```bash
xattr -dr com.apple.quarantine /Applications/ShrimpBreak.app
```

### Windows

`windows/` — C# (.NET Framework 4.8, Windows 10/11 기본 탑재 → 설치 불필요). Mac 에서 빌드한다 (.NET SDK 필요, `~/.dotnet`).

```bash
scripts/build_windows.sh               # → dist/ShrimpBreak-Windows.zip (공유용)
DEV_TOOLS=1 scripts/build_windows.sh   # 테스트 메뉴 포함
```

- Mac 과 다른 점: 메뉴바 대신 작업 표시줄 알림 영역(트레이) 아이콘, 남은 시간은 아이콘 툴팁으로 표시.
- 오류 기록: `%LOCALAPPDATA%\ShrimpBreak\error.log`

## 익명 사용 통계 설정

- 처음 실행 때 동의를 묻고(보내기/안 보내기), 메뉴 "익명 사용 통계 보내기"로 언제든 켜고 끌 수 있어요.

## Release Logs

날짜는 한국 시간 기준. 각 버전에는 바로 앞 버전 이후에 추가된 기능을 적었다.

### 0.4.0 — 2026-10-14

- 앉기 → 서기 → 움직이기 루틴. 메뉴 안에서 세 시간을 바로 입력하고, 0분인 루틴은 건너뜀 (켜진 루틴은 최소 하나)
- 위쪽 프리셋 라디오(10분·20분·30분·1시간·직접 입력): 프리셋은 켜진 루틴을 모두 같은 시간으로 맞춤
- 움직이기 차례의 메뉴바·트레이 아이콘, "움직이기 타이머 바로 시작"
- 움직이기 차례에도 자리 비움 판정을 하지 않음 (서기와 같음)
- 예전 타이머 설정(한 개 / 앉기·서기 따로)을 처음 실행 때 자동으로 옮김
- 익명 통계에 움직이기 설정 시간·하루 움직인 시간·바로 시작 횟수 추가
- Windows: 파도가 지나가는 동안만 새우 그림 캐시 상한을 올려 고해상도에서 덜 끊기게

### 0.3.2 — 2026-10-14

- 새우 크기 확률: 작은 새우가 더 자주 나오고 큰 새우는 가끔
- 파도: 물과 새우가 처음부터 끝까지 일정한 빠르기로 흘러감 (앞쪽은 물보다 빨라 새우가 몰리지 않음)
- Windows: 큰 새우는 튈 때 기울이지 않고 파도에서는 기울기 단계를 굵게 → 그림 메모리 절약

### 0.3.1 — 2026-10-14

- 새우·새우튀김 크기가 5cm ~ 화면 높이의 40% 사이에서 무작위
- 큰 새우가 바닥이 더 높은 옆 모니터로 넘어갈 때 바닥을 파고들던 문제 수정
- 파도: 좌우로 맞닿은 모니터들은 파도 하나가 이어서 지나감 (위아래로 쌓인 모니터는 각자)
- 파도: 앞쪽 끝이 바닥으로 자연스럽게 내려앉고, 띠마다 파고 차이를 크게, 물결 간격을 넓게
- 파도: 새우가 파도가 닿은 그 자리에서 띠 위로 올라타 울렁이며 함께 흘러감
- 파도: 왼쪽은 화면 끝까지 물이 찬 채로, 다 나갈 즈음 수위가 가라앉으며 끝남
- Windows: 그림 캐시에 메모리 상한(128MB)을 두고 오래 안 쓴 그림부터 지움

### 0.3.0 — 2026-10-14

- 새우를 클릭하면 파도가 밀려와 새우들을 태우고 쓸어가는 연출 (Mac·Windows)
- 파도 모양을 겹겹이 쌓인 물결 띠 5개로, 속도·불투명도 조정

### 0.2.0 — 2026-10-13

- 공유용 패키징 (Mac zip, 인증서 없이 지인에게) 과 테스트 메뉴를 뺀 공유용 빌드
- 메뉴바 아이콘을 타이머 차례마다 앉은 사람 ↔ 선 사람으로 교대
- 새우가 튀는 속도 20% 느리게
- 앉기·서기 시간 따로 설정 토글 (눌러도 메뉴가 닫히지 않음), 타이머 초기화, 앉기·서기 바로 시작
- Windows 트레이 앱 버전 (.NET Framework 4.8, 설치 불필요)
- 익명 사용 통계 (첫 실행 때 동의, 구글 시트, 켬/끔 기록)
- 서 있는 차례에 자리 비움으로 판정돼 새우 없이 넘어가던 문제 수정
- 새우끼리 부딪히면 튕김, 새우 증식 속도 슬라이더 (3초 ~ 1분)
- 새우튀김 비율 20%
- 메모리 누수 점검 (순환 참조·Windows 메뉴 항목 정리)

### 0.1.0 — 2026-10-12

- 첫 버전: 10분·20분·30분·1시간·직접 입력 타이머, 일시정지, 자리 비움 감지
- 시간이 되면 화면 바닥에서 새우(가끔 새우튀김)가 튀어나오고, 클릭하지 않으면 계속 늘어남. 하나를 클릭하면 모두 사라짐
- 여러 모니터를 넘나들며 튀고, 바깥 끝에서는 벽처럼 튕김
- 새우 크기를 실제 5cm로
